# Typsnitt

Tjänsten visar text med Nunito och Lexend. Filerna ligger här så att webbläsaren hämtar dem från sidans egen server och ingen uppgift om besökaren skickas till Google. De används i `styles.css` (`@font-face`).

| Fil | Typsnitt | Teckenområde |
| --- | --- | --- |
| `nunito-latin.woff2`, `nunito-latin-ext.woff2` | Nunito, vikt 400 till 900 (variabelt typsnitt) | Latin (inklusive å, ä, ö) och utökad latin |
| `lexend-latin.woff2`, `lexend-latin-ext.woff2` | Lexend, vikt 400 till 700 (variabelt typsnitt) | Latin och utökad latin |

Tecken utanför dessa områden (till exempel kyrilliska) visas med enhetens egna typsnitt.
